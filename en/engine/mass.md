# 质量与惯性张量

> 源码：`engine/MassProperties.java`

由一组轴对齐盒算出两样东西：**质心位置**与**完整 3×3 惯性张量**。

---

## 为什么不用球形惯量近似

不少体素物理实现会把惯性张量简化成球形：

```
I ≈ avg(Ixx, Iyy, Izz) × 单位矩阵
```

理由是「反正方块都差不多方」。对一整艘船那种大而匀的物体尚可。

**对这个插件完全不行。**

!!! danger "坍塌的主角恰恰是细长的柱子和薄薄的墙板"
    它们绕**长轴**和绕**短轴**的转动惯量差着一个数量级。

    球形近似之后，一根柱子会像哑铃一样绕自己的长轴翻滚 —— 那是最刺眼的假。
    观众不需要懂力学也一眼看得出不对。

### 惯性积也要保留

非对角项（惯性积）同样不能扔。

L 形、T 形的簇质心不在对称轴上，少了惯性积，它们翻转时的**进动**就是错的 ——
表现为「转着转着轴向自己漂移」这种说不清哪里怪但就是不对的运动。

## 怎么算

### ① 体积加权质心

```
totalVolume = Σ 8·hx·hy·hz
com = Σ (中心 × 体积) / totalVolume
```

质量按**体积加权**分配到各盒 —— 同一个簇里，台阶那半格自然只拿到一半质量。
不需要为「半砖比整砖轻」写任何特判。

### ② 逐盒「自身惯量 + 平行轴定理」

实心长方体绕自身质心：

```
Ixx = m/3 · (hy² + hz²)
Iyy = m/3 · (hx² + hz²)
Izz = m/3 · (hx² + hy²)
```

再用平行轴定理把每个盒的惯量搬到**整体质心**上累加，非对角项一并累加。

结果是行主序的 9 元素数组，绕**质心**。

### 退化兜底

半长为 0 的退化形状（`totalVolume <= 0`）会给一个球形兜底，
免得后面除出 `NaN` 把整个物理世界污染掉。这是防御而非物理。

## 状态原点是质心，不是形状原点

这是整个引擎最重要的一条约定，写在 `RigidBody` 上：

- `comX` / `comY` / `comZ` 存的是**质心的世界位置**
- 姿态四元数描述的是**绕质心**的转动

理由很直接：无外力时刚体绕质心自转。把状态原点选在别处，每一步积分都要额外做一次平移补偿，
而那个补偿在数值上很容易累积漂移。

### 但表现层要的是形状原点

表现层要的是**簇质心那个「名义中心」**（方块的局部偏移都相对它）。两者的关系由一组常量给出：

```
形状原点(世界) = 质心(世界) − R × comLocal
```

`comLocal` 就是 `MassProperties` 算出来的质心在形状局部系里的位置。

!!! note "为什么这个换算不能省"
    一根 1×8×1 的柱子，形状原点在几何中心，质心也在几何中心 —— 换算是恒等的。
    但一个 L 形的簇质心明显偏在拐角一侧，两者差着好几格。
    省掉换算的表现是「方块整体偏移了一段距离」，而且偏移量随形状变化，看起来毫无规律。

## 与质量的关系

总质量由上层给出：

```
质量 = 方块数 × ClusterPhysicsWorld.BASE_MASS_PER_BLOCK(1000) × materials.yml 的 density
```

所以 `materials.yml` 里 `density: 2.7` 的石头，一格是 2700 kg。

!!! tip "质量本身不影响自由落体"
    重力项里没有质量（`a = g`）。质量的差别体现在三处：
    碰撞时谁推得动谁、空气阻力（`dragK` 与密度成反比）、以及承重分析里的载荷。

    详见 [XPBD 求解器 · 积分](xpbd.md#-积分)。
