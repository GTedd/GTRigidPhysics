# `tnt.yml` —— 物理 TNT

只有一个键。

---

## `block-size`

```yaml
block-size: 1.0
```

控制发射 / 生成的物理 TNT 的尺寸。**碰撞盒、客户端渲染、质量都随此值缩放**。

| 值 | 效果 |
|---|---|
| `1.0` | **默认**。原版 TNT 大小（1 格方块） |
| `2.0` | 巨型 TNT（2 格），碰撞盒更大、渲染更大、质量按体积 **×8** |
| `0.5` | 小型 TNT（半格） |

下限 **0.25**（最小 1/4 格）。

!!! tip "质量随边长的立方缩放"
    越大越重、**抛得越近**。想要「大而且飞得远」得在发射力度上补回来。
